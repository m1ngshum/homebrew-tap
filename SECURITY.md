# Security

Use [private vulnerability reporting](https://github.com/m1ngshum/homebrew-tap/security/advisories/new) for security concerns. Do not post credentials, private client configs, internal endpoints, or unredacted diagnostics in issues.

The formula installs code from a checksummed vpn-pin release. Check the upstream release attestation and tag identity before updating it. Installation and CLI version tests do not establish live VPN compatibility.
